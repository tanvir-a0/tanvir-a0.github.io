MDP Value Iteration with GUI

This project implements the Markov Decision Process (MDP) Value Iteration algorithm with a Graphical User Interface (GUI) to visualize the changes in grid values with each iteration. The GUI is built using CustomTkinter for an intuitive and interactive experience.

Demonstrating reinforcement learning concepts through visual grid-based value iteration with real-time parameter adjustment.

Technology Python, CustomTkinter, MDP Algorithm
Focus Reinforcement Learning, Visualization, Interactive GUI

How to Use

  1. Clone the repository:
    git clone https://github.com/tanvir-a0/MDP-Value-Iteration-.git
  2. Navigate to directory:
    cd MDP-Value-Iteration-
  3. Install dependencies:
    pip install -r requirements.txt
  4. Run the application:
    python main.py
  5. Interact with GUI: Set parameters like grid size, reward values, discount factor, etc.
  6. Run Algorithm: Initiate the algorithm and observe grid value changes with each iteration.

Key Features

Value Iteration Interactive GUI Real-time Visualization Parameter Control Grid Customization Iteration Tracking
  • MDP Implementation: Complete Markov Decision Process Value Iteration algorithm
  • CustomTkinter GUI: Modern, intuitive interface for parameter adjustment
  • Real-time Updates: Watch grid values change with each iteration step
  • Configurable Parameters: Adjust grid size, rewards, discount factor
