Experiments Completed

  • Display & Graphics: C12832 LCD text rendering, custom fonts, and graphics primitives.
  • Input Devices: Joystick control with debouncing, potentiometer ADC reading, accelerometer (MMA7660).
  • Output Devices: RGB LED with PWM color mixing, speaker/buzzer tone generation.
  • Communication: Serial UART debugging, USB HID (keyboard/mouse emulation).
  • Applications: Snake game, bubble level, temperature monitoring, LED effects.
  • Attempted: Ethernet connectivity (DHCP), WebSocket communication, USB mass storage access.

Technology Stack

NXP LPC1768 ARM Cortex-M3 PlatformIO mbed Framework C/C++ C12832 LCD MMA7660 Accelerometer USB HID PWM I2C/SPI ADC
